🚀 Built a PowerShell-based Network Diagnostics & Port Connectivity Testing Tool

Recently worked on a small automation project using PowerShell to simplify basic network troubleshooting and connectivity validation tasks commonly performed by system administrators, SOC analysts, and infrastructure teams.

🔹 Features of the script:
✅ DNS resolution using Resolve-DnsName
✅ Host reachability testing using Test-Connection
✅ TCP port connectivity validation using Test-NetConnection
✅ Automated scanning of multiple commonly used ports
✅ User input support for dynamic IP testing
✅ Clean and readable console output for quick analysis

💡 Use Cases:

Server reachability validation
Firewall troubleshooting
Infrastructure health checks
SOC/network troubleshooting
Service availability verification
Basic network diagnostics automation
